## Evidence labels

- `source-listed`: The upstream collection lists the case; original post has not yet been independently checked by BeatAPI.
- `source-checked`: BeatAPI has checked the creator post, claimed model, prompt location, and output.
- `reproduced`: BeatAPI has run a documented reproduction with rights-cleared inputs.

Current entries are all `source-listed`. A link to a prompt is not permission to republish it. The catalog is a discovery and research resource; follow the original author for authoritative context.
