# Awesome Opus 5.5 Videos

由 [BeatAPI](https://beatapi.io/zh/opus-5-5-videos) 整理的 Claude Opus 5.5 创意编程案例索引。

这里的“视频”主要来自 HTML、Canvas、SVG、Three.js 等代码运行后的动画或交互场景，再由创作者录屏。**这不是把 Opus 5.5 描述成原生文生视频模型。**

[浏览案例页面](https://beatapi.io/zh/opus-5-5-videos) · [Opus 5.5 API](https://beatapi.io/zh/claude-opus-5-5-api) · [English](README.md)

首批 20 个案例在 [`cases/catalog.json`](cases/catalog.json)，分别覆盖动态视觉、讲解动画、3D 场景和游戏交互。每条保留原作者、X 原帖、上游提示词链接、技术标签以及证据和使用权限状态。

这批案例目前全部标记为 `source-listed`：它们来自 [上游合集](https://github.com/yihui-dev/awesome-opus5-5-videos)，BeatAPI 尚未逐条核对原帖或自行复现。我们使用原创摘要和链接，不在此镜像第三方提示词、图片或视频。
